# Examples

Run after building the package:

```sh
pnpm run build
pnpm run examples
```

- `descent.mjs` shows the function-level utterance-to-settlement descent.
- `action-apex.mjs` shows the registered action family induced into a dispatchable apex.
- `action-knowledge-vault.mjs` shows one induced apex projected as MCP tools, resources, and prompts, including registered resource and custom prompt legs.
- `operations-manifold.mjs` shows induced action apices read as carrier topology, including a cross-package codomain-domain edge and the derived MCP operations-manifold resource.
- `scripted-invocation-witnesses.mjs` shows direct `action.run` versus dispatch with `dataRoot`: the boundary play writes one EAVT invocation row and projects it back as state.
- `term-products.mjs` inspects exported RMN term catalogs as data and shows the evaluator, type checker, JSON bridge, and `evaluateRunTerm` path.
- `carrier-term-projection.mjs` shows the deterministic bridge between JSON carrier values and RMN value terms, including field, append, and manual term builders.
- `settlement-reader-terms.mjs` shows the settlement `readerTerms` catalog as `read . free` RMN bodies checked against the direct TypeScript readers.
- `carrier-kernel.mjs` shows the single-source carrier object: TypeBox schema, Ajv validation, `$id` registry resolution, composition address, and serializable morphism face.
- `schema-realization.mjs` shows JSON Schema predicates realized as structural readonly TypeScript-shaped data while validator refinements remain schema law.
- `operation-substrate.mjs` declares a tiny carrier/action pair and projects it through discovery and dispatch.
- `morphism-inspection.mjs` serializes action declarations as morphism carriers and dispatches them through the package's own `inspect` action.
- `witness-projection.mjs` witnesses observations into an append-only EAVT log, projects current state, commits a Datom record, compacts the live log, and writes a content-document cut.
- `four-charge-algebra.mjs` shows the FOUR value core, including held contradiction, the two orders, and gauge operations.
- `dihedral-gauge.mjs` shows the D4 symmetry surface of FOUR: the K4 order-preserving coset, the order-swapping coset, and the cross-order witness.
- `diataxis-four.mjs` shows Diataxis as a value-level read over package FOUR charge values, including axes and dualities.
- `relation-matrix.mjs` shows finite FOUR-valued relation matrices: duplicate knowledge joins, row/column profiles, state extension, duality, and checked transform witnesses and obstructions.
- `spatial-geometry.mjs` shows exact quadratic-field cut-and-project geometry: acceptance judgments, model-set sampling, gap spectra, and finite period refutation/non-refutation judgments.
- `typed-theory-consequence.mjs` shows finite consequence over predication data: derived rules, derivation search, closure rank, obstruction frontier, and predicate-word residue.
- `predication-fiber-logic.mjs` shows finite FOUR-valued predicate fibers, value-level linear-logic reads, cellwise fusion/residuum, and generator preservation checks.
- `formal-concept-analysis.mjs` shows the FCA Galois pair over predication-cell-shaped data as executable RMN terms.
- `chu-spaces.mjs` shows finite Chu-space duality over FOUR as executable RMN terms: dual, lookup, and double-dual witness.
- `bigraded-settling-cohomology.mjs` shows a FOUR census read into truth and contradiction rows, including collapse witness and obstruction cases.
- `settlement-analysis.mjs` shows exact settlement/evidence analysis: natural counts, matrix reads, spectral polynomial judgments, finite graph-Laplacian reads, harmonic judgments, conservation/completion judgments, charged control findings, and FOUR evidence distributions.
- `fixed-point-topology.mjs` shows knowledge/truth least and greatest fixed points, gap verdicts, fixed-point information, section partitions, and topology vitals.
- `firing-causality.mjs` shows charge-valued firing cohomology, firing-orbit reads, finite temporal causal order, cones, timelike/spacelike separation, and exact ordering fractions.
- `closure-regime.mjs` shows bounded ordinal closure search and finite / Scott / transfinite regime reads.
- `learning-depth.mjs` shows rote / automatization / conceptual-change / adaptive-expertise as a read over admitted closure-regime data.
- `learning-cycle.mjs` shows observed ascent and nontrivial-return judgments over a closure carrier's recorded orbit.
- `value-category-settling.mjs` shows finite/sample law judgments for value-category settling over Boolean and FOUR examples.
- `optimization-settling.mjs` shows optimization as value-category settling: measure/constraints as a value category, improvement as closure, and the optimum as a fixed-point witness.
- `probability-stochastic-settling.mjs` shows finite counting-measure probability, conditioning as reindexing, and Markov stationarity as a stochastic-closure fixed-point witness.
- `substitution-dynamics.mjs` shows finite substitution dynamics: Fibonacci and Padovan incidence matrices, derived characteristic polynomials, step-N co-incrementing witnesses, and an obstruction case.
- `representation-codecs.mjs` shows canonical JSON, schema assertion projection, markdown dataforms, Turtle/HTML escaping, and radial SVG recognition through the codec catalog.
- `projector-lattice.mjs` shows the holography projector lattice: built-in XML/SVG/radial classification plus a tiny authored restriction.
- `radial-svg-projection.mjs` shows a FOUR-valued predicate fiber projected through valuation data into deterministic, projector-recognized SVG bytes.
- `http-boundary-codecs.mjs` shows pure HTTP field and frame codecs: content type, negotiation, cache/range/preconditions, cookies, SSE, bearer auth, Link, and MCP JSON-RPC envelopes.
- `running-http-app.mjs` shows the running HTTP app object language: `.well-known` resources, response representations, JSON body reading, and topic-filtered SSE projection without starting a server.
- `runtime-transport-work.mjs` shows request/response, event stream, bounded claim session, and conflicted/open session as the four work types of the runtime boundary.
- `carrier-manifold.mjs` shows carrier `$id` mounting, including source fallback, an endomorphic carrier node, and OpenAPI/MCP/dispatch projection at that node.
- `lean-conformance.mjs` reads Lean-emitted golden fixtures and asserts representative rows through the public Node/RMN API.
