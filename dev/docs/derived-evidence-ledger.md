# Evidence ledger for the derived architecture

This ledger ties the architecture docs to local evidence.
It is here to keep the derivation from drifting into folder taste.

## Evidence Classes

`MATH`

- dependency-free RelMath derivation spine;
- no free data past primitive admission/articulation;
- local-to-global, closure, cohomology, persistence, relational, and computing organs.

`COMPUTATION`

- JSNode/ICK/RWIL mechanism;
- witness-time, source/channel separation, lenticular return projection;
- carrier-node mounting and action apex projection.

`NODE`

- TypeScript ESM, NodeNext, package exports, bins, PNPM workspace behavior, build outputs.

`CURRENT`

- facts about current code layout;
- useful as sediment and pressure, not as target authority.

When `CURRENT` contradicts `MATH`, `COMPUTATION`, or `NODE`, the ideal form follows the invariant and records the migration pressure.

## `lib/` Stratum Derivations

### `primitive`

Evidence:

- RelMath root: `Primitive` is first import; `Mark` is arbitrary atomic primitive.
- Category rules: free runtime values may appear only inside a base opaque carrier or at representation boundaries.

Consequence:

Primitive owns pure admitted base values and carrier atoms.

### `articulation`

Evidence:

- RelMath root: `Articulation` follows primitive admission; articulating is the base morphism and derived four-cell partition.
- Category rules: public morphisms normalize to `Mark -> Utterance -> articulate`.

Consequence:

Articulation owns the first relational act over primitive marks: utterances, cells, token/claim pairings, base articulation constructors.
